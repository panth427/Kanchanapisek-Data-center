คู่มือการทำงาน · สำหรับส่งต่อทีม

ขั้นตอนและ Prompt สำหรับสร้างรายงานวิเคราะห์แผนการศึกษา

ถอดกระบวนการที่ใช้จริงในการวิเคราะห์แผนพัฒนาฯ แผนปฏิบัติการ และการสังเคราะห์นโยบาย ให้ออกมาเป็นรายงาน HTML สำหรับผู้บริหาร — นำไปใช้ซ้ำกับงานลักษณะเดียวกันได้

๐

ภาพรวมกระบวนการ 4 ขั้น

ทุกงานวิเคราะห์เอกสารในชุดนี้เดินตามลำดับเดียวกัน ไม่ว่าจะเป็นการวิเคราะห์แผนเล่มเดียว การเทียบความสอดคล้องสองเล่ม หรือการสังเคราะห์นโยบายหลายแหล่ง

๑

ป้อนเอกสาร + โจทย์

อัปโหลด PDF และบอกให้ชัดว่าต้องการวิเคราะห์อะไร

→
๒

อ่าน + สกัดสาระ

ให้ AI อ่านทั้งเล่ม ดึงโครงสร้าง SWOT กลยุทธ์ ตัวชี้วัด งบ

→
๓

วิเคราะห์เชิงลึก

จุดเด่น–จุดที่ควรพัฒนา ความสอดคล้อง ข้อเสนอเชิงสร้างสรรค์

→
๔

ผลิตรายงาน HTML

จัดรูปแบบสำหรับผู้บริหาร พร้อมพิมพ์เป็น PDF

๑

หลักการเขียน Prompt ที่ทำให้ได้ผลดี

๑ ระบุบทบาทและบริบท

บอกว่าเรากำลังทำงานในฐานะอะไร (เช่น หัวหน้าฝ่ายวิชาการ) และเอกสารเป็นของหน่วยงานใด AI จะปรับมุมมองให้ตรง

๒ แยกงานเป็นขั้น

อย่าสั่งทุกอย่างในประโยคเดียว ให้วิเคราะห์ก่อน แล้วค่อยสั่งทำไฟล์ ทำให้ตรวจสอบระหว่างทางได้

๓ ขอทั้งวิจารณ์และข้อเสนอ

ไม่ใช่แค่ “บอกว่าดีหรือไม่ดี” แต่ขอ “ทางแก้” ด้วย เช่น ขอ TOWS หรือตัวชี้วัดที่ปรับแล้ว

๔ กำหนดผู้อ่านและรูปแบบ

บอกว่าใครจะอ่าน (ผู้บริหาร) และอยากได้รูปแบบไหน (ไฟล์ HTML พร้อมพิมพ์) ผลลัพธ์จะตรงการใช้งาน

๕ ให้ค้นข้อมูลล่าสุดเมื่อจำเป็น

เรื่องนโยบายที่เปลี่ยนบ่อย สั่งให้ค้นเว็บฉบับล่าสุดเสมอ อย่าพึ่งความรู้เดิม

๖ ต่อยอดจากงานก่อนหน้า

อ้างถึง “รายงานก่อนหน้า” ได้เลย AI จะรักษาธีมและความต่อเนื่องของเอกสารทั้งชุด

๒

ขั้นตอนที่ใช้จริง พร้อม Prompt แต่ละช่วง

๑

วิเคราะห์แผนเล่มเดียว (จุดเด่น–จุดที่ควรพัฒนา)

ใช้กับ: แผนพัฒนาฯ 5 ปี หรือเอกสารแผนใด ๆ
เป้าหมาย: เข้าใจเล่ม + ได้บทวิเคราะห์เชิงลึก
ทำอะไร: อัปโหลดไฟล์ PDF แล้วสั่งให้อ่านและวิเคราะห์ ให้ระบุตัวเราเองและหน่วยงานเจ้าของเอกสารเพื่อให้มุมมองตรง
◆ Prompt ที่ใช้
"นี่คือไฟล์แผนพัฒนาคุณภาพการศึกษา ระยะ 5 ปี ของ [ชื่อหน่วยงาน] ช่วยวิเคราะห์จุดเด่นและจุดที่ควรพัฒนาให้หน่อยครับ"
เคล็ดลับ: ถ้าตั้ง user preferences หรือบอกไว้ว่าเราเป็น “ครู/หัวหน้าฝ่ายวิชาการ” AI จะเชื่อมข้อเสนอกับบทบาทเราให้อัตโนมัติ เช่น ชี้จุดที่ฝ่ายวิชาการทำต่อได้
๒

สั่งทำเป็นไฟล์ HTML สำหรับผู้บริหาร + เพิ่มเครื่องมือ

ใช้กับ: แปลงบทวิเคราะห์เป็นเอกสารส่งมอบ
เป้าหมาย: ได้เอกสารพร้อมใช้ ไม่ใช่แค่ข้อความในแชท
ทำอะไร: หลังได้บทวิเคราะห์แล้ว สั่งให้รวมเข้ากับเครื่องมือเชิงกลยุทธ์ (เช่น TOWS Matrix, ตัวชี้วัด SMART) และผลิตเป็นไฟล์ HTML
◆ Prompt ที่ใช้
"ทำ 2 อย่างนี้ [เช่น TOWS Matrix + ตารางตัวชี้วัด SMART] เป็นไฟล์ HTML ผนวกเข้ากับบทวิเคราะห์ก่อนหน้า เป็นบทวิเคราะห์จุดเด่นและจุดที่ควรพัฒนา สำหรับผู้บริหารครับ"
เคล็ดลับ: คำว่า สำหรับผู้บริหาร สำคัญมาก มันทำให้ AI จัดหน้าเป็นสรุปกระชับ มีตาราง/แผนภาพ และพิมพ์เป็น PDF ได้ แทนที่จะเป็นข้อความยาว
๓

เทียบความสอดคล้องระหว่างสองเอกสาร

ใช้กับ: แผนปฏิบัติการปี ปะทะ แผน 5 ปี
เป้าหมาย: หาช่องว่าง/ความไม่ตรงกันระหว่างแผนแม่กับแผนลูก
ทำอะไร: อัปโหลดเอกสารเล่มที่สอง แล้วสั่งให้เทียบกับเล่มแรกที่วิเคราะห์ไปแล้ว AI จะจำบริบทเดิมได้
◆ Prompt ที่ใช้
"นี่คือไฟล์ร่างแผนปฏิบัติการปี [25xx] วิเคราะห์ความสอดคล้องกับแผนพัฒนาฯ [5 ปี] และวิเคราะห์จุดเด่น จุดที่ควรพัฒนา สร้างไฟล์ HTML สำหรับผู้บริหาร"
เคล็ดลับ: การเทียบสองเล่มมักเจอประเด็นที่มองข้าม เช่น จำนวนกลยุทธ์ไม่ตรงกัน หรืองบกระจุกบางพันธกิจ ลองถามเจาะเพิ่มว่า "งบแต่ละแผนงานสมดุลไหม"
๔

สังเคราะห์นโยบายหลายแหล่ง + ค้นข้อมูลล่าสุด

ใช้กับ: เตรียมข้อมูลก่อนร่างแผนรอบใหม่
เป้าหมาย: รวบรวมนโยบายฉบับล่าสุดหลายชั้นเป็นรายงานเดียว
ทำอะไร: สั่งให้ค้นเว็บหานโยบายฉบับปัจจุบัน (ที่อาจเปลี่ยนไปแล้ว) แล้วสังเคราะห์เชื่อมโยงเป็นแนวทางสำหรับแผนรอบต่อไป
◆ Prompt ที่ใช้
"ช่วยค้นคว้า นโยบาย/ยุทธศาสตร์ชาติ 20 ปี, นโยบาย ศธ., นโยบาย สพฐ. และพระบรมราโชบายด้านการศึกษา ร.10 ฉบับล่าสุด รวบรวมและจัดทำรายงานอย่างเป็นระบบ พร้อมแนวทางการนำไปจัดทำแผนพัฒนาฯ ระยะ 5 ปี [รอบถัดไป]"
เคล็ดลับ: ระบุคำว่า ฉบับล่าสุด เสมอ เพราะนโยบายการศึกษาเปลี่ยนตามรัฐบาล/รัฐมนตรี การค้นเว็บจะดึงฉบับปัจจุบันมาแทนของเก่า
๓

Prompt แม่แบบ (ปรับใช้ได้ทันที)

คัดลอกแล้วเติมข้อมูลในวงเล็บ ใช้เป็นจุดตั้งต้นสำหรับงานวิเคราะห์เอกสารแผนใด ๆ

▸ แม่แบบสำหรับวิเคราะห์เอกสารแผน "ฉันเป็น [บทบาท เช่น หัวหน้าฝ่ายวิชาการ] ของ [หน่วยงาน]
นี่คือไฟล์ [ชื่อเอกสาร] ช่วย:
1) อ่านและสรุปโครงสร้างหลักของเอกสาร
2) วิเคราะห์จุดเด่นและจุดที่ควรพัฒนา โดยดูทั้งการเชื่อมโยงนโยบาย คุณภาพตัวชี้วัด ความสอดคล้องของงบประมาณ และกลไกติดตาม
3) เสนอทางแก้ที่เป็นรูปธรรม เช่น [TOWS / ตัวชี้วัด SMART / ตารางติดตาม]
แล้วจัดทำเป็น ไฟล์ HTML สำหรับผู้บริหาร ที่พิมพ์เป็น PDF ได้"
๔

เช็กลิสต์ก่อนนำรายงานไปใช้จริง

  • ตัวเลข/ข้อเท็จจริง: ตรวจว่าตัวเลขงบประมาณ ปี พ.ศ. และชื่อบุคคล/ตำแหน่งถูกต้องตรงกับเอกสารต้นฉบับ (AI อาจใส่ค่าประมาณเชิงหลักการไว้ ต้องแทนด้วยค่าจริง)
  • นโยบายล่าสุด: ยืนยันว่านโยบายที่อ้างเป็นฉบับปัจจุบัน โดยเช็กจากเว็บทางการ (moe.go.th, สพฐ.) อีกครั้ง
  • บริบทเฉพาะหน่วยงาน: ปรับข้อเสนอให้เข้ากับบริบทจริงของโรงเรียน/กลุ่มโรงเรียน ไม่ใช้ค่าตัวอย่างตรง ๆ
  • พิสูจน์อักษร: ตรวจการสะกดและความถูกต้องก่อนเสนอ เพราะเป็นเอกสารทางราชการ
  • ผ่านความเห็นชอบ: เสนอคณะกรรมการสถานศึกษา/กลุ่มโรงเรียนก่อนประกาศใช้

หัวใจของการทำงานแบบนี้

แยกงานเป็นขั้น + ระบุบทบาทและผู้อ่าน + ขอทั้งวิจารณ์และทางแก้ + ให้ค้นข้อมูลล่าสุด สี่อย่างนี้คือสิ่งที่ทำให้รายงานทั้งชุดออกมาใช้งานได้จริง ไม่ใช่แค่ข้อความทั่วไป

เริ่มจากการวิเคราะห์ทีละเล่ม แล้วต่อยอดเป็นการเทียบความสอดคล้องและการสังเคราะห์นโยบาย โดยรักษาธีมเอกสารให้เป็นชุดเดียวกัน ทำให้ได้ชุดรายงานที่ผู้บริหารอ่านต่อเนื่องได้ และที่สำคัญ — ตรวจสอบข้อเท็จจริงเสมอ ก่อนนำไปใช้ในงานราชการ
